HELMETGUARD - YELLOW & BLACK DASHBOARD

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html, or open it with Google Chrome.
4. In the dashboard, choose a traffic video to preview it.
5. Use Clear feed to remove the selected video.

FILES
- index.html: dashboard structure and content
- style.css: yellow/black theme and responsive layout
- script.js: video preview, clock, navigation and demo FAQ assistant

IMPORTANT
This is a frontend prototype. Video upload currently previews the selected local video in the browser.
It does NOT run AI detection. The statistics and recent detection records are illustrative sample data.
To implement actual helmet/no-helmet detection, connect a Python backend and a trained object-detection model.
